# About diablo2.org

Scope: `/about` only. Amplify the established Diablo visual world: Exocet, Lato, cold carved stone, bone-white display, copper links and silver actions. Read mode with an invitation to participate.

Direction: People lead the page. A compact editorial introduction leads directly to two substantial owner profiles, with large names, separated project/role labels and generous clickable rows. A shared project catalogue explains the work using existing directory summaries and identifies each team member's involvement. The origin story is a quieter reading section; a clear Discord invitation closes the page.

Preserve all existing history, roles, verification policy and links. Data/team.ts remains the source of roles; directory records supply project descriptions. Do not invent portraits, biographies, accounts, quotes or project claims. Hellforge has no known listing URL, so keep it text. Retain optional GitHub/Discord personal contacts when present.

Responsive: two profiles side by side become stacked; project identity, description and affiliation columns collapse in reading order. No carousel, hidden content or horizontal page scrolling. Use page-local CSS. Do not change other routes, global styles, team data or unrelated sitemap/footer work.

Quality bar: owner names and connections feel intentional and personable, not a flat pair of generic info boxes. Real game frame assets reinforce the identity; long roles and sparse contacts must remain balanced. Official Discord and every existing role URL stay reachable. Desktop/mobile render and build/lint checks are required.
