# Homepage redesign

Scope: Homepage plus shared navigation, directory cards, page banners, and footer. Visitor mode: Read, with an atmospheric entrance into the community reference.

Audience: Returning Diablo II players choosing an installation, mod, server, or tools; readers seeking practical guides.

Primary action: Start playing via /play/getting-started. Secondary action: Explore mods. Four visible paths connect play, mods, servers, and tools. The next section is an ordered setup path, followed by existing popular projects and the complete guide list.

Direction: The user requested a Diablo website identity. The optional classic-versus-modern question was unanswered; classic Diablo II was the stated implementation assumption. Original gothic monastery art, wanderer and hellfire, antique gold Cinzel headings, blackened iron surfaces, blood-red actions.

Signature: Cinematic full-width gate scene with the wanderer at right and clear typography at left. A single brightness reveal respects reduced motion. Navigation paths illuminate on hover without displacement.

Constraints: Preserve existing factual content, routes, project data, search, and sourced metadata. Keep articles readable, mobile navigation keyboard accessible, and assets local and optimized. Original generated illustrations carry provenance beside each WebP. No approved UI comp; implementation is code-led.
