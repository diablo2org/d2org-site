If you last played Diablo II on a CRT, the good news is that the original game still runs, still has an active community, and is easier to set up than it was ten years ago. This guide covers the decisions you need to make before you start.

## Legacy Diablo II or Resurrected?

There are two games called Diablo II today.

- **Diablo II Resurrected** (2021) is Blizzard's remaster. It has new 3D graphics over the original game logic, controller support and current consoles. It is a separate purchase and a separate ecosystem.
- **Legacy Diablo II** is the original 2000 game and its 2001 expansion, Lord of Destruction. *This site is about legacy Diablo II*.

People still choose legacy Diablo II for the mods and private servers, the original look, low system requirements, and the tools that only exist for it. None of the mods or servers in our directory run on Resurrected.

## Classic or Lord of Destruction?

Almost everyone plays with the Lord of Destruction expansion installed. It adds two classes, a fifth act, runewords and 800×600 resolution. Every mod and server listed here requires it. You need both the base game and the expansion.

## Getting the game

If you own the original CD keys, add them to your Battle.net account. The account's downloads page provides installers for the base game and the expansion. Blizzard also sells legacy Diablo II through its online shop. We link to Blizzard rather than to any mirror.

A fresh install from Blizzard's installers gives you **patch 1.14d**.

## Which version should you use?

This depends on what you want to play.

| You want to... | Use |
| --- | --- |
| Play the unmodified game, or on the official realms | 1.14d, as installed |
| Play a major mod or private server | Whatever that project's launcher sets up. Most use 1.13c |
| Play singleplayer with PlugY and classic tools | 1.13c is the best supported |

Version 1.13c matters because 1.14 merged the game's code into a single executable, which broke many older mods and tools. Most of the modding scene stayed on 1.13c as a result. See [Diablo II versions explained](/play/versions) for the full story.

<Callout type="tip">
You don't usually need to downgrade by hand. SlashDiablo, Diablo 09, Project Diablo 2, Path of Diablo and Median XL each ship a launcher that sets up the version they need.
</Callout>

## Vanilla, mod or private server?

- **Vanilla singleplayer** is the original game with nothing changed. Add [PlugY](/tools/plugy) if you want a shared stash and more storage.
- **Official realms.** Blizzard's legacy Battle.net realms run 1.14d. Expect an old game with a small population.
- **Vanilla-like private servers** play the game you remember, online with other people. [SlashDiablo](/servers/slashdiablo) runs 1.13c with skills, monsters and items left alone, plus a few conveniences such as global chat and an official maphack. [Diablo 09](/servers/diablo09) goes further back, to patch 1.09, before synergies existed.
- **Vanilla-plus private servers** such as [Project Diablo 2](/servers/project-diablo-2), [Path of Diablo](/servers/path-of-diablo), [Resurgence](/servers/resurgence) and [Annihilus](/servers/annihilus) keep the classic feel but rebalance skills and add new items and endgame content. Project Diablo 2 and Path of Diablo run seasonal ladders and have the largest player bases.
- **Overhauls** such as [Median XL](/mods/median-xl) rebuild the game. Treat them as a different game that shares Diablo II's engine.

If you want Diablo II as it was, with people to trade and play with, start on SlashDiablo. If you want something new built on top of it, try a vanilla-plus server. Read [Diablo II private servers explained](/guides/private-servers-explained) before choosing.

## A recommended modern setup

1. Install Diablo II and Lord of Destruction from Blizzard's installers.
2. Check it launches. On Windows 10 and 11 it usually does. If not, see [Windows 10 & 11](/play/windows).
3. Add a modern renderer such as [D2DX](/tools/d2dx) or [D2GL](/tools/d2gl) for proper scaling, higher frame rates and widescreen. The [graphics guide](/guides/modern-diablo-2-graphics) compares them.
4. For singleplayer, consider [PlugY](/tools/plugy) for stash space.
5. If you're joining a mod or server, install its launcher and follow its instructions. It will usually handle steps 3 and 4 for you.

On Linux or Steam Deck, see [Linux](/play/linux) and [Steam Deck](/play/steam-deck).
