A private server is a community-run replacement for Battle.net. Players connect with a patched or launcher-managed copy of legacy Diablo II, and the server hosts games, characters and ladders. Most of today's active legacy multiplayer happens on private servers rather than the official realms.

## Why they exist

Blizzard's legacy realms still run, but they've barely changed in over a decade. Private servers offer things the official realms don't:

- Regular seasonal resets, which give everyone a fresh start at the same time.
- Balance changes that make more builds viable.
- New items, endgame content and quality-of-life features such as loot filters and bigger stashes.
- Active anti-cheat, moderation and community management.

## How they differ

The most useful way to compare servers is by how far they move from the original game.

- **Vanilla-like** servers keep the game as it was, with small conveniences. [SlashDiablo](/servers/slashdiablo) runs 1.13c with skills, monsters and itemisation untouched, adding global chat, an official maphack and a few drop tweaks. [Diablo 09](/servers/diablo09) preserves patch 1.09, from before synergies and the 1.10 runewords.
- **Vanilla-plus** servers keep the look, pacing and most of the systems, but rebalance skills and add items and endgame content. [Project Diablo 2](/servers/project-diablo-2) and [Path of Diablo](/servers/path-of-diablo) are the largest. [Resurgence](/servers/resurgence) and [Annihilus](/servers/annihilus) are long-running projects with their own item and endgame systems.
- **Overhaul realms** host multiplayer for a mod that changes almost everything, such as [The Sin War](/servers/median-xl), the Median XL realm.

Other factors to consider:

- **Season structure.** How often the ladder resets, and whether there's a non-ladder realm where characters persist.
- **Trading.** Where trading happens, and what the community uses as currency.
- **Launcher.** Most servers install through their own launcher, which also manages the game version and renderer.
- **Singleplayer.** Some projects also offer an offline mode that uses the same rules.

## Running your own

Most private realms are built on [PvPGN](/tools/pvpgn), open-source Battle.net server software. It handles logins, chat and the realm's character database. The Diablo II game server that runs the games themselves, D2GS, is a separate piece that PvPGN doesn't include. PvPGN is enough for a small realm for friends.

## Safety

- Download launchers only from the server's official site.
- Keep private server installs separate from your main Diablo II install. Most launchers do this for you.
- Use a unique password for each server account.
- Some realms sell items, loot boxes or currency for real money. The server pages note which ones do.
