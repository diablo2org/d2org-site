Name : The name of the set.   
Prefix : The first half of the name of each item in the set.   
level : Minimum level in the game that the weapon will appear.   
NumItems : Number of items in the set.   
NumProperties : Number of properties that the complete set possesses.   
transform : Flag to see if item color differs from normal.   
transformcolor : The color that the set items will be changed to if the transform flag is checked.   
ItemType1 : Name of base item for the first item in the set.   
Item1 : Code of base item for the first item in the set.   
Item1Suffix : The second half of the name of the first item in the set.   
ItemType2 : Name of base item for the second item in the set.   
Item2 : Code of base item for the second item in the set.   
Item2Suffix : The second half of the name of the second item in the set.   
ItemType3 : Name of base item for the third item in the set.
