Well, i discovered this, messing around with morphing, i thought it was pretty cool, so i decided to share it with all you :)

You will need-

D2Excel

Stats.txt

First open stats.txt

Go to the row that has the state 'monsterset', id 176.

Copy that row, and paste it at the bottom of the file

Change the name to Speedmorph

And change the ID to the number after the collumn before it.

Next go to the gfxclass column and replace the existing number with 574

Now just put the state name on your unique small charm

For Example

Code:

prop1             par1          min1   min2 state        Speedmorph      1        1

Now, go test your new speed charm, i suggest testing it with teleport, its fun :)
