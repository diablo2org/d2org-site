This is a resource list over all event functions (that can be used in any file that can handle events, itemstatscost, skills for example).

1 = Chilling armor retaliation(Ice Bolt?)  
2 = Frozen armor retaliation(Freeze)  
3 = Shiver armor retaliation  
4 = Iron Maiden effect  
5 = Life Tap effect  
6 = attacker takes physical damage  
7 = knockback  
8 = howl  
9 = stupidity(monster goes blind)  
10 = attacker takes lightning damage  
11 = attacker takes fire damage  
12 = attacker takes cold damage  
13 = damage to mana  
14 = freeze  
15 = openwounds  
16 = crushing blow  
17 = add mana  
18 = add hp  
19 = slow  
20 = cast skill  
21 = cast skill  
22 = Absorbs physical  
23 = damage transfer to master when BloodGolem takes damage  
24 = Absorbs physical/fire/lightning/cold (unknown on magic, I'm sure poison ignores it)  
25 = Absorbs fire/lightning/cold  
26 = Still unknown  
27 = whatever it is that is so special when a Clay Golem takes damage, as opposed to when one of the other pets takes damage  
28 = add hp  
29 = Redemption effect (visual you get the same effect as Paladin's redemption skill) and it makes the body not targetable any longer by skills like (Find Item/Find Potion/Corpse Explosion)  
30 = cast skill  
31 = reanimate
