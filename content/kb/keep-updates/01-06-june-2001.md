**June 1st** - By Fusman  
I updated the Werzion X mod today, it's up to v. 1.08 now. The biggest new thing with this release is how you install the mod. It is just a simple exe file that you double-click and the mod is installed. You dont need to mess with your patch\_d2.mpq file in your diablo 2 directory. The installer puts a new shortcut on your desktop and in your start menu d2 folder. Those shortcuts run the mod and your old d2 shortcuts will still run normal d2. The installer also puts a readme file and an uninstall option in your start menu d2 folder.  
Check out the Werzion X page for more info and the download.
